# SC Agris - Gestion des notes (by Studio SR)
Application Android native autonome (100 % hors-ligne + synchronisation bidirectionnelle Google Sheets).

## Comment récupérer votre fichier `.apk` en 2 minutes sur GitHub :
1. Créez un nouveau dépôt (**New repository**) sur votre compte [GitHub](https://github.com).
2. Cliquez sur **uploading an existing file** (ou poussez le contenu de ce dossier décompressé).
3. Attention : assurez-vous de bien glisser **le dossier `.github`**, le dossier **`app`**, et les fichiers **`build.gradle`**, **`settings.gradle`** et **`gradle.properties`** à la racine du dépôt.
4. Validez avec **Commit changes**.
5. Cliquez sur l'onglet **Actions** en haut de votre dépôt GitHub : le script **Build SC Agris APK** se lance tout seul !
6. Au bout de 2 minutes, cliquez sur le workflow terminé (coche verte ✅) et téléchargez **`SC_Agris_Buvette_APK`** tout en bas dans la section **Artifacts**.
